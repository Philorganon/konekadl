Keunggulan Utama

Dirancang dengan prinsip privasi sejak baris kode pertama.

Ringan, fokus pada nomor Indonesia, dan bebas pelacak komersial.

01

Arsitektur Zero-Trust

Tidak ada kunci HMAC atau AES di dalam APK. Semua proses kriptografi berlangsung di Cloudflare Worker edge server.

02

Nomor Asli Tidak Disimpan

Nomor yang dinormalisasi langsung di-hash dengan HMAC-SHA256. Nomor plaintext hanya lewat memori sementara.

03

Nama Terenkripsi AES-256-GCM

Setiap variasi nama kontak (maksimal 60 karakter, hingga 12 variasi per nomor) dienkripsi dengan IV 12-byte acak.

04

Tanpa Iklan & Izin Berlebihan

Tidak ada SDK iklan, GPS, foto, atau pelacak pihak ketiga. Izin tulis kontak (WRITE_CONTACTS) diblokir total.

05

Kontrol Penuh di Tab Privasi

Pantau status izin & jumlah kontak tersimpan, hapus cache lokal, atau tarik seluruh kontribusi Anda kapan saja.

Cara Kerja

Dari instalasi hingga cek nomor dalam empat langkah.

Langkah 4

Transparansi Privasi

Jelas apa yang disimpan dan apa yang tidak pernah disentuh.

Yang Disimpan di Arsip
  • ID Nomor HMAC-SHA256 Hash berkunci rahasia dari nomor Indonesia yang dinormalisasi (08…).
  • Nama Terenkripsi AES-256-GCM Hanya teks nama yang disanitasi (1–60 karakter) dengan IV acak per entri.
  • ID Perangkat Anonim (UUID v4) Disimpan aman di Android EncryptedSharedPreferences untuk menandai kontribusi perangkat.
Yang Tidak Pernah Disimpan
  • Nomor Telepon Asli (Plaintext) Server hanya memproses nomor di memori sementara sebelum menghasilkan HMAC ID.
  • Data Pribadi & Pelacakan Tidak ada email, foto, catatan kontak, lokasi GPS, riwayat panggilan, atau SDK iklan.
  • Kunci Enkripsi di Sisi Klien File APK tidak pernah menyimpan kunci HMAC maupun AES.

Pertanyaan Umum

Hal yang sering ditanyakan sebelum mengunduh.

Apakah nomor telepon saya dan kontak saya disimpan dalam bentuk asli?

Tidak. Nomor telepon dinormalisasi lalu diubah menjadi hash HMAC-SHA256 di server. Nama kontak dienkripsi dengan AES-256-GCM sebelum disimpan.

Mengapa Koneka meminta izin baca kontak (READ_CONTACTS)?

Koneka memakai model buku kenalan bersama. Begitu izin baca kontak diberikan, kontak bernomor Indonesia disetorkan secara terenkripsi dan fitur pencarian langsung terbuka.

Bisakah Koneka mengubah atau menghapus kontak di HP saya?

Tidak. Koneka hanya meminta izin baca (READ_CONTACTS) dan secara eksplisit menghapus izin tulis (WRITE_CONTACTS) di manifest Android.

Bagaimana cara menghapus data kontribusi saya dari server?

Buka tab Privasi di aplikasi lalu ketuk Tarik Semua Kontribusi. Server akan menghapus seluruh entri nama yang terhubung dengan ID perangkat Anda.

Instalasi Android

Siap mencoba Koneka di ponsel Anda?

  1. Ketuk tombol Unduh Koneka APK di samping.
  2. Buka file koneka-debug.apk dari notifikasi atau File Manager.
  3. Jika diminta Android, aktifkan Izinkan dari sumber ini untuk browser Anda.
  4. Ketuk Instal, buka Koneka, lalu berikan izin Kontak.
